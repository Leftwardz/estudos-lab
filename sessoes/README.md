# Sessões de Estudo

Pasta para anotações e exercícios de cada sessão de estudo.

## Convenção de nomes

```
YYYY-MM-DD-<trilha>-modulo-NN.md
```

Exemplos:

- `2026-07-17-git-modulo-01.md`
- `2026-07-18-api-auth-db-modulo-03.md`

## Template de sessão

Copie o bloco abaixo ao iniciar uma nova sessão:

